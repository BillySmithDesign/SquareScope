# Contributing to SquareScope

Thanks for helping improve SquareScope! 🚀

## Before contributing

Never include:

- Square access tokens
- customer information
- merchant secrets
- private API responses
- production environment files
- personally identifiable information

## Development

Clone the repository, install dependencies, copy `.env.example` to `.env.local`, add your own Square credentials and run the development server.

## Pull requests

Please explain:

1. What changed
2. Why it changed
3. How it was tested

Screenshots are encouraged for UI changes.

## Security

Never open a public issue containing credentials or private customer data.

If a credential is accidentally exposed, revoke or rotate it immediately.
